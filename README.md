##  Descripción del Proyecto

**PharmaDash** es un sistema integral para la gestión de inventario, ventas y análisis de datos en farmacias. Desarrollado siguiendo los principios de **Clean Architecture** y los **12 Factores de Aplicaciones Modernas**.

### Objetivo

Proporcionar una solución robusta, escalable y mantenible para la administración farmacéutica, con especial enfoque en:

-  Gestión de inventario con alertas inteligentes
-  Sistema de ventas transaccional con cálculo automático de impuestos
-  Dashboard analítico con KPIs en tiempo real
-  Control de acceso basado en roles (RBAC)
-  Arquitectura limpia y desacoplada
